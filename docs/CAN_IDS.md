# CAN κινητήρα Leon 1P (PQ35): τι είναι κάθε ID

Πηγή: δημόσιο αρχείο DBC `vw_pq.dbc` του [commaai/opendbc](https://github.com/commaai/opendbc) (άδεια MIT),
συν ό,τι επιβεβαιώσαμε στο αυτοκίνητο. **Τα bytes μετράνε από 0**, από αριστερά προς τα δεξιά όπως στον πίνακα της οθόνης.
Τιμές 16 bit: χαμηλό byte πρώτα (π.χ. `99 13` → 0x1399).

✅ = επιβεβαιωμένο στο αυτοκίνητο · ❓ = από το DBC, θέλει έλεγχο

## Πώς το επιβεβαιώνουμε

Στην οθόνη, **όποιο byte αλλάζει γίνεται κόκκινο**. Κάνε μία κίνηση τη φορά και δες ποιο κοκκινίζει:

1. Γκάζι στο ρελαντί → 280 byte 2-3 (στροφές), 280 byte 5 και 380 byte 2 (πεντάλ), 588 byte 4 (boost)
2. Φρένο → 288 byte 2, 4A8 byte 2-3
3. Τιμόνι δεξιά/αριστερά → 0D0 byte 4-5
4. Φλας, φώτα, όπισθεν → 390
5. Οδήγηση → 1A0, 4A0, 5A0
